4Animated bubble experimental

Apple says a link can show a short looping video that autoplays (muted) in Messages. This records a short loop of your design as an MP4 (4 s, or up to 8 s of your GIF or video playing inside the card). Not tested on a real iPhone yet, so treat it as an experiment. If it doesn't animate, the still cover still shows.

6Upload from your iPhone

  
    
    
  1. Tap each Save button above. Safari asks to download, tap Download. The files land in Files › Downloads with the right names.
    2. 
    
  2. In Safari, go to github.com and open your repo (the one this site is in).
    3. 
    
  3. Tap Add file › Upload files, then choose your files › Browse › Downloads, and pick the cover, the page (and the video if you made one). Keep the names exactly as they are.
    4. 
    
  4. Tap Commit changes. GitHub takes about a minute to publish.
    5. 
    
  5. Tap Is it live? above (or open your link in Safari: it should jump to the real link).
    6. 
    
  6. Paste your link in iMessage, wait for the bubble to appear, then send.
    7. 
  

  
No Downloads? Use Copy page code, then on GitHub tap Add file › Create new file, name it like fame.html, paste, and commit. Upload the cover from Files the same way. Don't upload the cover from Photos: Photos renames it.

  
Changed a design? Give it a new short name. iMessage caches bubbles, so an old link keeps its old look.
